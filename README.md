# نئوآنکی (NeuAnki) 🃏

کلون کامل و مدرن AnkiDroid برای اندروید — با **جاوا خالص**، طراحی **نئومورف تیرهٔ لاکچری**، رنگ تاکیدی **زمردی** و رابط کاملاً **فارسی RTL**.

## ✨ امکانات

- 📦 **ایمپورت دک‌های واقعی انکی (apkg)** — کارت‌ها، یادداشت‌ها، انواع یادداشت (استاندارد و کلوز)، پیشرفت قبلی کارت‌ها و فایل‌های مدیا (عکس/صدا)
- 🧠 **زمان‌بند SM-2** (هم‌خانوادهٔ الگوریتم انکی) — مراحل یادگیری، فارغ‌التحصیلی، لغزش، ضریب آسانی و fuzz
- 🎴 **مرور ترکیبی** — چهار دکمهٔ دوباره/سخت/خوب/آسان با پیش‌نمایش فاصلهٔ بعدی **به‌همراه ژست‌های سوایپ**:
  - سوایپ راست = خوب | سوایپ چپ = دوباره | سوایپ بالا = آسان | سوایپ پایین = سخت
- ✍️ **پاسخ تایپی** با مقایسهٔ رنگی حرف‌به‌حرف (پشتیبانی از `{{type:...}}`)
- 🎴 پشتیبانی کامل از قالب‌های انکی: `{{cloze}}`، `{{hint}}`، `{{FrontSide}}`، بخش‌های شرطی، صوت `[sound:...]` و عکس‌ها
- ↩️ **بازگردانی (Undo)** آخرین پاسخ
- 📊 **آمار و نمودار** — مرورهای ۳۰ روز گذشته، پیش‌بینی ۳۰ روز آینده، توزیع وضعیت کارت‌ها، زنجیرهٔ روزها
- 🔍 **مرورگر کارت** — جستجو، ویرایش، تعلیق، دفن، انتقال بین دک‌ها و حذف
- ⏰ **یادآور روزانه** با WorkManager و نوتیفیکیشن
- 🔒 **کاملاً محلی** — بدون اکانت، بدون سرور؛ همه‌چیز روی خود دستگاه (SQLite)
- 🌙 فقط تم تیرهٔ نئومورف با فونت وزیرمتن

## 🛠 نحوهٔ بیلد (قدم‌به‌قدم)

### پیش‌نیازها
1. **Android Studio** نسخهٔ Hedgehog (2023.1.1) یا جدیدتر — از [developer.android.com/studio](https://developer.android.com/studio) بگیر.
2. اتصال اینترنت برای بارگیری Gradle 8.6 و وابستگی‌ها (شامل JitPack برای کتابخانهٔ نمودار).
3. یک دستگاه اندروید با **API 24+ (اندروید ۷ به بالا)** یا امولاتور.

### بیلد
1. فایل زیپ را Extract کن.
2. Android Studio را باز کن → **Open** → پوشهٔ `NeuAnki` را انتخاب کن.
3. صبر کن تا **Gradle Sync** تمام شود (بار اول چند دقیقه طول می‌کشد).
4. دستگاه یا امولاتور را وصل کن و **Run ▶** را بزن.

### گرفتن فایل APK
- از منو: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
- خروجی: `app/build/outputs/apk/debug/app-debug.apk`

> اگر Gradle Sync خطای `distributionUrl` داد، در Android Studio از `File → Settings → Build Tools → Gradle` گزینهٔ Gradle JDK را روی **Embedded JDK (17/21)** بگذار.

## ⚙️ بیلد بدون اندروید استودیو (GitHub Actions)

پروژه دارای `.github/workflows/build.yml` است؛ اگر سورس را روی GitHub بگذاری، **خودش APK را می‌سازد** و در تب **Actions ← Artifacts** قرار می‌دهد.

برای راهنمای کامل قدم‌به‌قدم (هم روش آپلود ساده با مرورگر، هم روش Git با توکن شخصی) فایل **[GITHUB-GUIDE.md](GITHUB-GUIDE.md)** را بخوان.

> 🔐 یادآوری امنیتی: توکن گیتهاب فقط برای مصرف شخصی خودت است؛ آن را در چت یا جایی به اشتراک نگذار.

خلاصهٔ سریع:
1. ریپوی Public بساز و محتویات پوشه را آپلود کن (یا با git push کن).
2. تب **Actions** ← بیلد «Build NeuAnki APK» اجرا می‌شود (~۵ دقیقه).
3. از بخش **Artifacts** فایل `NeuAnki-debug-apk` یا `NeuAnki-release-apk` را بگیر.
4. برای انتشار رسمی، تگ `v1.0` بزن تا هر دو APK به تب **Releases** هم اضافه شوند.

## 📂 ساختار پروژه

```
NeuAnki/
├── app/src/main/java/com/neuanki/app/
│   ├── App.java                     ← کانال نوتیفیکیشن + فونت + فارسی‌سازی
│   ├── db/                          ← دیتابیس SQLite (کارت، یادداشت، دک، revlog)
│   ├── sched/Scheduler.java         ← زمان‌بند SM-2 (خالص و تست‌پذیر)
│   ├── tpl/TemplateEngine.java      ← موتور قالب کارت‌های انکی
│   ├── imp/ApkgImporter.java        ← واردکنندهٔ apkg (زیپ + SQLite + مدیا)
│   ├── widget/                      ← ویجت‌های نئومورف سفارشی (Layout/Button/Icon)
│   ├── remind/                      ← یادآور روزانه (WorkManager)
│   ├── util/Util.java               ← اعداد فارسی، تاریخ، ابزار HTML
│   └── ui/                          ← اکتیویتی‌ها (Main, Reviewer, Browser, Stats, Settings)
└── app/src/main/res/                ← تم نئومورف، فونت وزیرمتن، آیکون‌ها، لی‌اوت‌های RTL
```

## 📦 ایمپورت دک‌های انکی

1. در اپ روی **FAB (+)** بزن → «وارد کردن فایل apkg».
2. فایل `.apkg` دک را انتخاب کن.
3. تمام! کارت‌ها، پیشرفت قبلی و مدیا وارد می‌شوند.

> ⚠️ **نکتهٔ مهم:** اگر فایل apkg با انکی نسخهٔ ۲٫۱٫۵۰ به بالا ساخته شده و پیام «فرمت جدید» دیدی، در Anki دسکتاپ هنگام **File → Export** تیک **«Support older Anki versions (slower/larger files)»** را بزن و دوباره خروجی بگیر. این همان روشی است که خود AnkiDroid هم برای حداکثر سازگاری پیشنهاد می‌کند.

## 🎛 تنظیمات

- **سقف کارت‌های جدید روزانه** (پیش‌فرض ۲۰)
- **سقف مرور روزانه** (پیش‌فرض ۲۰۰)
- **مراحل یادگیری** به دقیقه (پیش‌فرض `1,10`)
- **یادآور روزانه** با انتخاب ساعت

## 📝 نکات فنی

- `minSdk 24` / `targetSdk 34` / `compileSdk 34` — بدون کاتلین، کاملاً جاوا
- دیتابیس: SQLite با اسکیمای ساده‌شدهٔ انکی (decks, notes, cards, revlog, notetypes, prefs)
- ترتیب صف مرور: ابتدا کارت‌های یادگیریِ سررسید، سپس ترکیب هر ۳ کارت مرور با ۱ کارت جدید (مثل انکی)
- ایمپورت با شناسه‌های انکی انجام می‌شود و در صورت تداخل، شناسه‌ها به‌طور خودکار جابه‌جا (shift) می‌شوند — ایمپورت تکراری یک دک از دست نمی‌رود
- فونت وزیرمتن هم در UI بومی (res/font) و هم داخل WebView کارت‌ها (@font-face) استفاده شده
